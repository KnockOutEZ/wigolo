# Adopters

Companies and projects that use wigolo. Every entry here was added by someone
from that organization — this is the list the website's "Used by" logos come
from, so nothing appears on it without a request.

Using wigolo at work or in a project? Add yourself:

- **Open a pull request** adding a row below, or
- **[File an adopter issue](https://github.com/KnockOutEZ/wigolo/issues/new?template=adopter.yml)**
  and it will be added for you.

Include a logo (SVG preferred, PNG at least 256 px tall) if you'd like one on
the site. You can ask to be removed at any time.
